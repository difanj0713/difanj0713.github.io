The phenomenon

01

A model does not say everything it computes.

People rarely say every thought behind an answer. Models have a similar gap: the words you see are only the end of a much larger computation, and useful signals can remain inside without ever reaching the output.

02

The signal you need may already be there.

We found those signals in text classification, AI safety, document search, and agent monitoring. Read those internal states differently, and the same model can classify better, catch more risks, and return better search results.

03

For compact tasks, better can be cheaper.

A label, safety score, or search ranking does not need a paragraph of generated text. A small readout can skip decoding. If the useful signal appears early, you can stop the computation there too.

So when is this worth trying?

Whenever the result you need is compact and efficiency matters. Start with the model you already have and test whether the signal is readable inside.

How internal signals become a readout

01 · Activations

Every token lights up every layer.

For a single input sentence, record the activation of every internal unit, at every layer, at every token position. This block is what one forward pass leaves behind.

02 · Pooling

Collapse the sentence into a vector.

Pool over token positions, keeping for each unit the response that matters most anywhere in the sentence. The token axis disappears and each layer is left with one vector.

03 · Probing

Ask each layer, one at a time.

Fit a sparse linear probe on each layer independently. Under an L1 penalty, the magnitude of the learned weights is a usable statement of how much each unit contributed. That is its saliency.

04 · Sparsifying

Most units are not about the task.

Keep the smallest set of units carrying the bulk of each layer's decision and drop the rest. Roughly three quarters of them go. The accuracy does not go with them.

05 · Integrating

Depth is a feature, not a stage.

The survivors are carried forward and gathered across layers, so a decision taken at any depth can draw on everything the network computed below it.

06 · Readout

One head. One forward pass. No decoding.

What comes out is a classifier that reads the model's own state instead of waiting for its output. It fits in kilobytes, it trains on a laptop, and it answers without generating a single token.
