The research question

01

The output is a narrow interface.

A model exposes its final output, not every task-relevant signal formed across its layers. For labels, scores, rankings, or embeddings, that distinction can matter.

02

Evidence across four domains

In text classification, content safety, visual document retrieval, and agent safety, our methods recover useful evidence from internal representations while keeping the backbone frozen.

03

Direct readouts can reduce inference cost.

Compact task-specific components avoid full-model updates. Classification readouts can also skip token-by-token decoding and, when the relevant state occurs early, stop before the final layer.

When internal readouts are useful

When the target is a label, score, ranking, or embedding and adaptation or serving cost matters, the central empirical question is whether that signal is accessible in the model’s internal representations.

SPIN workflow for a layer-wise internal readout

01 · Layer activations

A forward pass exposes activations across depth.

For one input, SPIN collects each internal unit’s activation at every token position and layer.

02 · Pooling

Pooling produces one vector per layer.

Max pooling retains each unit’s strongest response across token positions, removing the token axis.

03 · Probing

Sparse probes estimate unit saliency.

An L1-regularized linear probe is fitted to each layer; coefficient magnitude provides a task-specific saliency score.

04 · Sparsifying

A cumulative threshold controls sparsity.

SPIN retains the smallest subset whose normalized probe weights account for a chosen share of each layer’s decision.

05 · Integrating

Selected features form a cross-layer representation.

The selected activations are concatenated across layers into multi-grained features for classification.

06 · Classification

A compact classifier returns the prediction.

The frozen backbone runs once; the classification head requires no token generation and can use a validated early exit.

One principle. Many domains.

The projects share a frozen backbone and an internal readout, but adapt the method and evaluation to each task.

Visual document retrieval

MINER identifies retrieval-ready internal layers in frozen multimodal encoders, aligns the remaining layers, and fuses them into one dense embedding. It improves visual document retrieval while preserving a single-vector index and standard dot-product search.
