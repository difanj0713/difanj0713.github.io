The phenomenon

01

A model computes its answer through dozens of layers, then speaks from the last one.

A language model builds up its reading of an input step by step. Early layers pick up surface form, middle layers assemble meaning, late layers turn meaning back into tokens so that something can be said. Whatever the model has worked out has to pass through that final state to become an output.

Which means the final state is a bottleneck. And it is the only thing a classification head, a guard model, or a dense retriever ever gets to look at.

02

The judgment is often already there, well before it is spoken.

This is testable, and the sharpest test we have is on agent safety. Hand a guard model two tool-calling trajectories that are byte-for-byte identical except for the schema of the one tool the agent actually calls. One is safe, one is not. The guard's own verdict tells them apart at chance.

Now read the same model's internal states instead. A single linear direction, estimated out of fold, orders those pairs correctly up to 0.98 of the time. The distinction was formed. The output channel dropped it.

03

What gets dropped is sparse, sits mid‑stack, and is almost free to recover.

Across text classification, content moderation, multimodal retrieval, and agent trajectories, the same three properties keep turning up. The evidence is linearly readable, so a linear probe is enough. It is concentrated: a few percent of a layer's coordinates carries it. And it peaks in the middle of the network, above the depth everything is normally read from.

So recovering it does not take a fine-tune. It takes one forward pass and a head measured in kilobytes.

01 · Activations

Every token lights up every layer.

For a single input sentence, record the activation of every internal unit, at every layer, at every token position. This block is what one forward pass leaves behind.

02 · Pooling

Collapse the sentence into a vector.

Pool over token positions, keeping for each unit the response that matters most anywhere in the sentence. The token axis disappears and each layer is left with one vector.

03 · Probing

Ask each layer, one at a time.

Fit a sparse linear probe on each layer independently. Under an L1 penalty, the magnitude of the learned weights is a usable statement of how much each unit contributed. That is its saliency.

04 · Sparsifying

Most units are not about the task.

Keep the smallest set of units carrying the bulk of each layer's decision and drop the rest. Roughly three quarters of them go. The accuracy does not go with them.

05 · Integrating

Depth is a feature, not a stage.

The survivors are carried forward and gathered across layers, so a decision taken at any depth can draw on everything the network computed below it.

06 · Readout

One head. One forward pass. No decoding.

What comes out is a classifier that reads the model's own state instead of waiting for its output. It fits in kilobytes, it trains on a laptop, and it answers without generating a single token.
