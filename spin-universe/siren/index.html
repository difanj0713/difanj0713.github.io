The headline result

Four backbones.
Four stronger guards.

Each comparison starts from the same underlying LLM. One side safety-tunes the whole model; SIREN keeps it frozen and reads what is already inside.

The interface change

Generative guards write a verdict.
SIREN reads one.

The model stays intact. Safety neurons from informative layers become one continuous harmfulness score.

The latency advantage

Skip decoding.
Get the verdict sooner.

A generative guard reads the input, then writes its answer token by token. SIREN returns one score from the forward pass already in flight.
