Why this matters
at index scale.

Late interaction gets fine-grained matches by storing many vectors for every page. That cost multiplies across the entire corpus. Dense retrieval stores one vector, but normally reads only the model’s final layer. MINER found a better bargain: recover the useful structure already present inside the dense backbone, then hand the existing index one stronger vector. Across ViDoRe V1, V2 and V3, eight of nine backbone averages moved up.

Inside MINER

Some layers are ready to read. Others need lining up first.

The deployment payoff

The index never learns a new trick.

No token-level index. No new scorer. MINER changes the embedding that enters the database, not the database itself.
